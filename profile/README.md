## Open-source tools

- **[mail-auth-check](https://github.com/Joepify/mail-auth-check)**: check SPF, DMARC and DKIM for any domain (Python, no dependencies, MIT).
- **[php-eol-check](https://github.com/Joepify/php-eol-check)**: see which PHP version a site exposes and whether it still gets security fixes (MIT).
- **[ai-crawler-access-check](https://github.com/Joepify/ai-crawler-access-check)**: what do GPTBot, ClaudeBot, OAI-SearchBot and 14 other crawlers really get from your site (MIT).
- **[geo-aeo-checklist-nl](https://github.com/Joepify/geo-aeo-checklist-nl)**: get found in ChatGPT, Copilot and Google AI Overviews, with official sources (CC BY 4.0).
- **[schema-templates-nl](https://github.com/Joepify/schema-templates-nl)**: JSON-LD templates for Dutch businesses (KvK, VAT, services, FAQ) (CC0).
- **[webshop-regels-nl](https://github.com/Joepify/webshop-regels-nl)**: checklist of Dutch webshop rules 2026 with official sources (CC BY 4.0).
